# 0001. Clean-room reimplementation under MIT

Date: 2026-09-18
Status: Accepted

## Context

The reference project (TownGeneratorOS) is GPL-3.0. The owner wants a permissive licence so the tabletop community can reuse the engine.

## Decision

Reimplement from ideas only; no code from GPL sources. MIT licence, copyright "CityGenerator contributors".

## Consequences

CONTRIBUTING.md carries the clean-room policy. Reviewers reject ported code. The medieval core takes longer to reach parity than a port would.
