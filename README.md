# CityGenerator

A browser-based procedural city generator for tabletop maps, inspired by
[watabou's Medieval Fantasy City Generator](https://github.com/watabou/TownGeneratorOS)
and extended with:

- modern infrastructure: railways, train yards, container ports, dry docks,
  industrial zones and facilities;
- wealth and density modelling that shapes layout and is visible as overlays;
- a general feature-placement engine with manual pinning and gap filling;
- topography with rivers, coasts, contours and terrain-aware roads and rail;
- an LLM assistant that answers questions about the map and edits it;
- a static site on GitHub Pages built with TypeScript, Vite and React.

The project is at the **design stage**. Start here:
